# Lecture 19: Generation, Reduction, Unraveling into Trees, Bulldozer

**What this lecture covers:** (1) the **generation theorem** (cutting a frame down to what is reachable preserves truth), (2) **reductions** with examples, (3) the **reduction theorem**, (4) every formula valid on a frame is valid on ∘ or on •, (5) **tree frames**, (6) every rooted frame is a reduction image of an **intransitive tree** (unraveling), (7) the **bulldozer theorem** (transitive frames come from strict partial orders).

**How to read each section.** Every topic has three layers:
1. **Math:** the precise statement or proof (what you write in exams).
2. **Room-and-light picture:** the building-with-doors story (for intuition).
3. **Normal explanation:** the same idea in ordinary words, without the room picture.

**Quick recap from earlier lectures:**
- x⇑ = {x} ∪ (points reachable in one or more steps). A **generated subframe** is the subframe induced by such an upward closed set. A point x is a **root** if x⇑ = W.
- R* = reflexive and transitive closure of R, so **xR*y iff y ∈ x⇑**.
- **Dead end** = a point with no successor. ∘ = a single reflexive point, • = a single irreflexive point.
- (𝔉,x) ⊨ φ for a **frame** means φ is true at x under **every** valuation (validity at a point). 𝔉 ⊨ φ means valid at every point.
- **K** = formulas valid on all frames.

## 1. The generation theorem

### Math
**Theorem (Generation).** If 𝔑 is a **generated submodel** of 𝔐, then for every point x in 𝔑 and every modal formula φ:

> **(𝔑,x) ⊨ φ  iff  (𝔐,x) ⊨ φ.**

**Proof idea (not on the board).** Induction on φ. Variables and Boolean connectives look only at x, and x has the same facts in both models. For □ψ: since 𝔑 is generated, it is **closed under successors**, so every successor of x in 𝔐 is already in 𝔑 (with the same arrows). By induction ψ has the same truth value at each such successor in both models, so □ψ (and ◇ψ) has the same value at x. ∎

**Corollary.** If 𝔊 is a generated subframe of 𝔉 (the board writes ⊆ with a small arrow), then for every x in 𝔊 and every formula φ:
1. **(𝔊,x) ⊨ φ iff (𝔉,x) ⊨ φ**
2. **𝔉 ⊨ φ implies 𝔊 ⊨ φ**

*Why the corollary follows (my filling in):* a valuation on 𝔊 can be extended arbitrarily to 𝔉, and a valuation on 𝔉 can be restricted to 𝔊. The theorem says truth at points of 𝔊 is the same either way.

**Corollary.** **K = { φ ∈ Form_ML : 𝔉 ⊨ φ for all rooted frames 𝔉 }.**
*Why:* "⊆" is trivial (rooted frames are frames). For "⊇": if φ fails at x in some frame, then by the generation theorem it fails at x in the subframe generated by x, which is a **rooted** frame. So φ is not valid on all rooted frames either.

> **Room-and-light picture:** from room x you can only ever walk through doors into rooms reachable from x. So you can **demolish every room you cannot reach from x** and nothing changes for anyone standing in the surviving part. A person standing in room x cannot tell the difference between the whole building and the building cut down to what is reachable.

> **Normal explanation:** □ and ◇ only look at successors, and the successors of a point inside an upward closed set stay inside it. So truth at x depends only on the part of the frame reachable from x. This is the global version of Lecture 17's locality result (where the bound was n steps). The last corollary is useful: to decide whether a formula is in K, you may restrict attention to **rooted** frames, i.e. frames where one point reaches everything.

## 2. Reductions and examples

### Math
**Definition (standard; the board does not restate it on these pages).** A map f from 𝔉 = ⟨W,R⟩ **onto** 𝔊 = ⟨V,S⟩ is a **reduction** of 𝔉 to 𝔊 if for all x, y ∈ W:
- **(R1, forth)** xRy ⇒ f(x) S f(y)
- **(R2, back)** f(x) S z ⇒ there is y ∈ W with **xRy and f(y) = z**

For models 𝔐 = ⟨𝔉,U⟩ and 𝔑 = ⟨𝔊,V⟩ there is a third condition:
- **(R3)** x ∈ U(p) iff f(x) ∈ V(p), for every variable p.

(All examples on the board agree with this definition; I checked them below.)

**Example (page 2).** Let (a) be the **transitive irreflexive** chain on {0,1,2,…} with n R m iff n < m (drawn with arrows only between consecutive points). Let (b) be the **proper 2-point cluster** ②, and (c) the **single reflexive point** ∘.
- (a) is reduced to (b) by **f(n) = n mod 2**.
- (a) is reduced to (c) by **g(n) = 0 for all n**.

*Check for f.* Forth: n < m gives f(n) R f(m), because every pair in the cluster is related. Back: if f(n) R z with z ∈ {0,1}, pick any m > n with m mod 2 = z. Such an m exists. ✓
*Check for g.* Forth: every pair is mapped to the reflexive pair ✓. Back: ∘R∘, and n has a successor m > n ✓.

**Remark on the transitive closure (board).** If we **do not take the transitive closure**, i.e. we read (a) as having **only the arrows n → n+1**, then **(a) is not reducible to (b), but is reducible to (c)**.
*Why:* for (b), the back condition fails. The point f(n) sees itself in ②, so we would need a successor m of n with the same parity, but the only successor is n+1, which has the other parity. For (c), the back condition only needs n to have some successor, and n+1 works.

**Fact (board).** **No reflexive point can be mapped by a reduction to an irreflexive one.**
*Proof:* if xRx then forth gives f(x) S f(x), so f(x) is reflexive. (The converse direction is allowed: irreflexive points can be sent to reflexive ones, as in f(n) = n mod 2.)

*(The sketch of (c) on the board looks like two small circles; the map g forces the image to be a single point, so (c) is ∘.)*

> **Room-and-light picture:** a reduction is a way of **squashing a big building onto a smaller one**: several rooms may be glued to the same room, but the squashing must respect doors in two ways. (forth) If there was a door between two rooms, there must be a door between the two rooms they were squashed onto. (back) If the squashed-onto room has a door to some room z, then **every** original room glued to it must have a door to **some** room that gets squashed onto z. In the "n mod 2" example, all even rooms are glued to room 0 and all odd rooms to room 1.

> **Normal explanation:** a reduction is a structure-preserving surjection of frames, and it is also called a **p-morphism** or **bounded morphism** in many textbooks. Two conditions: it must not create arrows that do not exist (forth), and it must not lose any possible move (back). The "back" condition is the one people forget. It is exactly what makes the next theorem true. Note that a reduction can merge points, so unlike an isomorphism it is not one-to-one.

## 3. The reduction theorem

### Math
**Theorem (Reduction).** If f is a reduction of a model 𝔐 to a model 𝔑, then for every point x in 𝔐 and every formula φ:

> **(𝔐,x) ⊨ φ  iff  (𝔑,f(x)) ⊨ φ.**

**Corollary.** If f is a reduction of the frame 𝔉 to the frame 𝔊, then for every point x in 𝔉 and every formula φ:
1. **(𝔉,x) ⊨ φ implies (𝔊,f(x)) ⊨ φ**
2. **𝔉 ⊨ φ implies 𝔊 ⊨ φ**

**Proof idea (not on the board).** Theorem: induction on φ. Variables: condition (R3). Boolean connectives: immediate. □ψ: suppose (𝔑,f(x)) ⊭ □ψ. Then some z with f(x) S z has ψ false at z in 𝔑. By the back condition there is y with xRy and f(y) = z, and by induction ψ is false at y in 𝔐, so □ψ fails at x. Conversely, if ψ is false at some successor y of x in 𝔐, then by forth f(y) is a successor of f(x), and by induction ψ is false there. (◇ is dual.) ∎
Corollary (ii): given **any** valuation V on 𝔊, define U(p) = f⁻¹(V(p)) on 𝔉. Then f is a reduction of models, and since 𝔉 ⊨ φ, the formula is true at every point of (𝔉,U). As f is **onto**, every point of (𝔊,V) is the image of such a point, so φ is true everywhere in (𝔊,V).

> **Room-and-light picture:** if you squash the building onto a smaller one **and carry the lights along**, every room says the same thing about every formula as the room it was squashed onto. So the big building and its squashed copy have the same "truths". Since the squashed building has fewer rooms, it is easier to analyse.

> **Normal explanation:** a reduction preserves the **truth of every modal formula**, so frames that reduce onto 𝔊 can only validate things 𝔊 validates. **Use it backwards to refute formulas:** if φ is **not** valid on 𝔊, then φ is not valid on **any** frame that reduces onto 𝔊. For example, the McKinsey formula fails on the 2-point cluster ② (Lecture 18), and the chain (ℕ, <) reduces onto ② via n mod 2, so McKinsey is not valid on (ℕ, <) either. Likewise Löb's formula fails on ∘ (Lecture 17), and (ℕ, <) reduces onto ∘, so Löb fails on the chain as well, which agrees with Lecture 17's direct check.

## 4. Every frame-valid formula is valid on ∘ or on •

### Math
**Proposition.** If a modal formula φ is valid in some frame, then it is also valid either in **∘** or in **•**.

**Proof.** Suppose 𝔉 ⊨ φ.
- **Case 1: 𝔉 contains a dead end x.** Then ⟨{x}, ∅⟩ = • is a **generated subframe** of 𝔉 (x has no successors, so {x} is upward closed). By the generation corollary, • ⊨ φ.
- **Case 2: otherwise every point of 𝔉 has a successor.** Then the constant map **f(x) = ∘** for all x is a **reduction** of 𝔉 to ∘. Forth: any pair of points goes to the reflexive pair (∘,∘). Back: ∘ S ∘, and every x has some successor y with f(y) = ∘. By the reduction corollary, ∘ ⊨ φ. ∎

*(My note, not on the board: this is the key step in Makinson's theorem, which says that every consistent normal modal logic is contained in the logic of ∘ or the logic of •.)*

> **Room-and-light picture:** take any building. Either it has a **dead-end room**, in which case the one-room building with no door (cut out of it) keeps the truths. Or **every room has a door out**, in which case you can squash the whole building into one room with a door to itself. Either way, anything true in the big building survives in one of these two tiny buildings.

> **Normal explanation:** this shows how limited "valid on some frame" is as a source of logics. No matter how complicated the frame, its logic sits inside the logic of one of two one-point frames. The proof uses the two tools of this lecture, **generation** (cut away) and **reduction** (squash), in the two cases of a yes/no split: "does a dead end exist?".

## 5. Tree frames

### Math
A modal frame 𝔉 = ⟨W,R⟩ is called a **tree** if the **reflexive and transitive closure R\*** of R (that is, for x, y ∈ W: **xR\*y iff y ∈ x⇑**) is a **tree partial order** on W.

The criterion used on the next pages is: for every point x, the set of points below it, **x⇓** (the points that reach x, including x), is **finite and linearly ordered by R\***. *(The board does not spell out the full definition of "tree partial order" on this page; this is the working meaning from page 7.)*

An **intransitive tree** is a tree whose own relation R is intransitive, so R is exactly the "immediate successor" relation: every non-root point has exactly one R-predecessor.

> **Room-and-light picture:** a tree is a building shaped like a **family tree** or a branching staircase: from the root room the corridors branch out, and no two branches ever merge again. Looking back from any room, there is exactly **one path** to the root.

> **Normal explanation:** a tree is a frame where the "above/below" order has no cycles and no merging. The closure R\* turns the one-step relation into the "reachable" order, and the tree condition says that the past of each point is a finite chain. In an **intransitive** tree we draw only the immediate arrows, and R\* supplies the rest.

## 6. Every rooted frame is a reduction image of an intransitive tree (unraveling)

### Math
**Theorem.** Every **rooted** modal frame 𝔊 = ⟨V,S⟩ is a reduct of some **intransitive tree**.

**Proof (board).** Let v₀ be a root of 𝔊. Define

> **W = { ⟨v₀, v₁, …, v_{n−1}, vₙ⟩ : v₀ S v₁ S … S v_{n−1} S vₙ }**   (all finite S-paths starting at the root)

> **⟨v₀,…,vₙ⟩ R ⟨v₀′,…,v_m′⟩  iff  m = n+1 and vᵢ = vᵢ′ for i ≤ n**   (R is "extend the path by one step")

Clearly 𝔉 = ⟨W,R⟩ is an **intransitive** frame with root ⟨v₀⟩.
**𝔉 is a tree**, since the set of points below ⟨v₀,…,vₙ⟩ is **finite** and **linearly ordered** by the reflexive transitive closure of R, namely

> ⟨v₀⟩ R ⟨v₀,v₁⟩ R … R ⟨v₀,…,v_{n−1}⟩ R ⟨v₀,…,v_{n−1},vₙ⟩.

The map **f : W → V onto V**, defined by **f(⟨v₀,…,vₙ⟩) = vₙ** (the last point of the path), is a **reduction of 𝔉 to 𝔊**.

*Why f is a reduction (my check):* **Onto:** because v₀ is a root, every v ∈ V is reached from v₀ by some finite path, so v = f(path). **Forth:** ⟨v₀..vₙ⟩ R ⟨v₀..vₙ,v_{n+1}⟩ means vₙ S v_{n+1}. **Back:** if vₙ S z then the extended path ⟨v₀..vₙ,z⟩ is in W, is an R-successor, and maps to z. ∎

**Corollary.** **K = { φ ∈ Form_ML : 𝔉 ⊨ φ for all intransitive trees 𝔉 }.**
*Why:* "⊆" is trivial. For "⊇": if φ fails on some frame, it fails on a rooted generated subframe 𝔊 (generation). By the theorem 𝔊 is a reduction image of an intransitive tree 𝔉, and by the reduction corollary (𝔉 ⊨ φ ⇒ 𝔊 ⊨ φ) the formula φ fails on 𝔉.

> **Room-and-light picture:** pretend you are wandering the building from the root room and **write down your whole walk** as a list of rooms. Make a new building whose rooms are these **walks** (not the original rooms): a walk has doors only to its one-step extensions. This new building is a **tree**: from every walk there is only one way back to the start. Mapping each walk to the room where it currently ends squashes the tree back onto the original building.

> **Normal explanation:** this is **unraveling** (also called unfolding). It replaces cycles and merging by an infinite tree that has exactly the same local behaviour. It explains why trees are enough for K: any "bad" frame can be unravelled into a tree without changing which formulas hold. Practical consequence: a satisfiable modal formula has a **tree-shaped** model (the tree model property from your revision notes).

## 7. Strict partial orders and the bulldozer theorem

### Math
An **irreflexive and transitive** binary relation is called a **strict partial order**.

**Theorem (Bulldozer).**
1. **Every transitive frame is a reduct of some strict partial order frame.**
2. **Every quasi-order frame is a reduct of some partial order frame.**

**Proof of (1) (board, completed by me where marked).** Let 𝔊 = ⟨V,S⟩ be a transitive frame. To each point x ∈ V associate a set **x⁺**:
- **{⟨x,i⟩ : i = 0,1,2,…}** (infinitely many copies) if the cluster C(x) is **non-degenerate**
- **{⟨x,0⟩}** (one copy) if C(x) is **degenerate**

Let **W = ⋃ x⁺**. Fix a **well-ordering** x₀, x₁, …, x_ξ, … of the points of **every cluster** C in 𝔊. Define R on W by:
- **Same cluster:** if C(x_ξ) = C(x_η), then **⟨x_ξ,i⟩ R ⟨x_η,j⟩ iff i < j, or (i = j and ξ < η)**
- **Different clusters:** for distinct C(x) and C(y), **⟨x,i⟩ R ⟨y,j⟩ iff xSy**

*(The board's rule for the same-cluster case is written cramped; I read it as the lexicographic rule above, and I checked that it makes R transitive, irreflexive and gives a reduction.)*

The board concludes: **R is transitive and irreflexive**, i.e. a strict partial order, and 𝔊 is a reduct of 𝔉 = ⟨W,R⟩. The proof stops there. Here is the verification:

- **Irreflexive.** Within a cluster, ⟨x_ξ,i⟩R⟨x_ξ,i⟩ would need i < i, or i = i and ξ < ξ. Impossible. Across clusters there is no pair with the same cluster.
- **Transitive.** Within one cluster R is a lexicographic order on pairs (i, ξ), so it is transitive. If the three points lie in three different clusters, xSy and ySz give xSz by transitivity of S. If two of them share a cluster, use that same-cluster points x ∼ y satisfy xSy (or x = y), so combining with S transitive gives the required S-relation. The case where the first and third share a cluster but the middle does not is impossible: xSy and ySz with z ∼ x would make ySx, forcing y ∼ x.
- **Reduction f(⟨x,i⟩) = x** *(map added by me; the board does not write it)*:
  - **Onto:** each x has the copy ⟨x,0⟩.
  - **Forth:** across clusters this is the definition. Within a cluster, ⟨x,i⟩R⟨y,j⟩ gives either x ≠ y with x ∼ y, so xSy, or x = y with i < j, which can only happen in a non-degenerate cluster, where every point is reflexive, so xSx.
  - **Back:** if xSz and C(z) ≠ C(x), then ⟨x,i⟩R⟨z,0⟩. If z ∈ C(x), the cluster is non-degenerate and ⟨x,i⟩R⟨z,i+1⟩ because i < i+1.

**Proof of (2) (not on the board; my derivation).** A quasi-order is reflexive and transitive, so all its clusters are non-degenerate. Apply part (1) to get a strict partial order 𝔉 = ⟨W,R⟩ and the reduction f. Let R° = R ∪ {⟨w,w⟩ : w ∈ W} be the reflexive closure. Then R° is a partial order (reflexive, transitive, antisymmetric since R is strict). The map f is still a reduction: the new pairs (w,w) go to (f(w),f(w)), which is related because 𝔊 is reflexive (forth), and the back condition already held with R ⊆ R°. ∎

> **Room-and-light picture:** a lounge (cluster) is a bunch of rooms that all see each other, which creates loops. The **bulldozer** flattens every lounge into an **endless one-way staircase** of copies of its rooms: copy 0 of every room, then copy 1 of every room, and so on, in a fixed order, with a door from every step to all later steps. Rooms in different lounges keep the same doors as before. Now nothing loops back, and squashing each copy back to its original room gives the old building.

> **Normal explanation:** a transitive frame can have clusters, i.e. points that see each other (and reflexive points). The bulldozer theorem says you can always **replace each cluster by a strictly ordered, infinite stack of copies** without changing what formulas hold, because the resulting frame reduces onto the original. The result is a **strict partial order**, which is a much cleaner kind of frame. Degenerate points need only one copy because they have no loop. The consequence (not stated here) is that for logics of transitive frames, one can work with strict partial orders instead.

## Worked example: unraveling a 2-cycle (my own)

**Frame 𝔊.** V = {r, s}, S = {(r,s),(s,r)}, root r. (It is not transitive, and both points are irreflexive.)
- **Unraveling:** W = all S-paths from r: ⟨r⟩, ⟨r,s⟩, ⟨r,s,r⟩, ⟨r,s,r,s⟩, … . R extends a path by one step. This is an **infinite intransitive chain**.
- **Reduction map:** f gives the last point: r, s, r, s, … .
- **Check back condition:** f(⟨r⟩) = r and r S s; the successor ⟨r,s⟩ maps to s ✓.
- **Consequence:** any formula valid on the infinite chain is valid on the 2-cycle (corollary of the reduction theorem). Conversely, a formula failing on the 2-cycle fails on this chain.

## Common mistakes
1. **Forgetting the back condition of a reduction.** Monotone maps are not enough. Example: the one-step chain n → n+1 does not reduce onto ② by n mod 2.
2. **Reading validity the wrong way.** If f reduces 𝔉 onto 𝔊, then 𝔉 ⊨ φ implies 𝔊 ⊨ φ, **not** the converse. Reductions are used to **refute** formulas on 𝔉 by refuting them on 𝔊.
3. **Same for generated subframes:** validity passes from 𝔉 **down to** a generated subframe, not up. (Truth at a **point** x passes both ways in the generation theorem.)
4. **Mixing up reflexive and irreflexive images.** Reflexive points go to reflexive points, but irreflexive points may go to reflexive ones.
5. **Unraveling needs a root.** Without a root, the "onto" part fails because some points are not reachable by any path from v₀.
6. **Bulldozer copies.** Degenerate clusters get one copy, non-degenerate get infinitely many, and the order inside a cluster is lexicographic: **first the copy index i, then the position ξ**.
7. **Confusing "K is the logic of trees" with "all frames are trees".** The corollaries say the **set of valid formulas** is the same, not that the frames are.

2. Why is the rootedness of 𝔊 needed in the unraveling theorem?
3. Unravel V = {r}, S = {(r,r)} (a single reflexive point). What is the intransitive tree, and what does f do?
4. Use Section 3 to show that Löb's formula □(□p → p) → □p is not valid on any frame in which every point has a successor.
5. Describe the bulldozer construction for a 2-point proper cluster {a, b} with a = x₀, b = x₁.

**Answers**
1. xRx gives f(x) S f(x) by the forth condition, so f(x) is reflexive.
2. The map f must be **onto** V. A point not reachable from v₀ by a finite S-path would not be the last point of any path in W, so it would not be in the image of f.
3. W = {⟨r⟩, ⟨r,r⟩, ⟨r,r,r⟩, …}, an infinite chain with each point R-related only to the next. f sends every path to r. (This is the reduction of the chain onto ∘, the same shape as the chain in Lecture 17.)
4. Such a frame reduces onto ∘ by the constant map (Section 4, Case 2). Löb's formula fails on ∘ (Lecture 17, with V(p) = ∅). Since validity passes from 𝔉 to the reduct, failure on ∘ implies failure on 𝔉.
5. Both points are reflexive, so each gets infinitely many copies: ⟨a,i⟩ and ⟨b,i⟩ for i = 0,1,2,… . In one cluster, ⟨x_ξ,i⟩ R ⟨x_η,j⟩ iff i < j or (i = j and ξ < η), so the order is ⟨a,0⟩ < ⟨b,0⟩ < ⟨a,1⟩ < ⟨b,1⟩ < … , an infinite **strict linear order** (an ω-chain). The map f(⟨x,i⟩) = x sends it back to the cluster.

## One-page summary
- **Generation theorem:** truth at x is the same in a model and in a generated submodel. So **validity passes down** to generated subframes, and **K = formulas valid on all rooted frames**.
- **Reduction (p-morphism):** onto map with **forth** (xRy ⇒ f(x)Sf(y)) and **back** (f(x)Sz ⇒ ∃y: xRy, f(y)=z). For models also keep the valuation (R3).
- **Reduction theorem:** (𝔐,x) ⊨ φ iff (𝔑,f(x)) ⊨ φ. So 𝔉 ⊨ φ ⇒ 𝔊 ⊨ φ. Use it to refute.
- **Examples:** (ℕ,<) reduces onto ② (n mod 2) and onto ∘ (constant). With only n → n+1 arrows, it still reduces onto ∘ but not onto ②. Reflexive points never map to irreflexive ones.
- **Proposition:** valid on some frame ⇒ valid on ∘ or on •. Dead end ⇒ generated subframe •; no dead end ⇒ constant map to ∘.
- **Tree:** R\* (reflexive-transitive closure) is a tree order, i.e. each point's past is finite and linear.
- **Unraveling:** every rooted frame is a reduction image of the intransitive tree of finite paths from the root, via f = last point. So **K = formulas valid on all intransitive trees**.
- **Bulldozer:** every transitive frame is a reduct of a strict partial order frame (copies ⟨x,i⟩, infinitely many for non-degenerate clusters, one for degenerate ones). Every quasi-order frame is a reduct of a partial order frame.
